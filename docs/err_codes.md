# 错误码表

HTTP 失败响应统一格式：`{ "err_code": number, "err_msg": string }`（snake_case 键名）。

| err_code | HTTP | 含义 | 来源 |
|----------|------|------|------|
| 40100 | 401 | 未登录 / 鉴权失败 | `httpx` JWT 中间件、`sys` 登录 |
| 40300 | 403 | 无权限 | 工作流审核/撤回、转码回调签名校验 |
| 40000 | 400 | 参数错误 | 各 domain 参数校验 |
| 40401 | 404 | 媒资不存在 | `asset` |
| 40402 | 404 | 栏目/上传会话/工作流实例不存在 | `catalog`、`asset/upload`、`workflow` |
| 40403 | 404 | 转码组/任务不存在 | `transcode` |
| 40901 | 409 | 工作流锁定冲突 | `workflow` Redis 锁 |
| 42202 | 422 | 工作流状态非法 | `workflow` 状态机 |
| 50000 | 500 | 内部错误 / 配置缺失 | `httpx` 兜底、转码配置 |

## 说明

- 成功响应无包装，直接返回业务 JSON（camelCase）。
- 50100（功能开发中）预留给 AI 等占位接口，当前路由未启用时由中间件返回 50000。
